# CS 465 Module One - Travlr Getaways

This project is the Module One working shell for the customer-facing Travlr Getaways web application. It uses Node.js and the Express framework to serve the provided static HTML, CSS, and image assets.

## Run locally

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in a browser.

The static Travlr pages are located in `public/`, the stylesheet is in `public/css/`, and images are in `public/images/`.

## Module One Git workflow

If this folder is inside your course Git repository, create/switch to the Module One branch and commit the completed shell:

```bash
git checkout -b module1
git add .
git commit -m "Baseline Express Website - static only"
git push --set-upstream origin module1
```

If `module1` already exists locally, use `git checkout module1` instead of creating it again.
